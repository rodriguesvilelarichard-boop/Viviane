# Custo da Cozinha

App para calcular o custo de quitandas, salgados e bolos e montar a lista de compras.
Os dados ficam só no aparelho de quem usa (nada vai para a internet).

## Publicar (GitHub Pages)
1. Envie estes arquivos para a raiz do repositório.
2. No GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
3. Depois de 1–2 minutos o app fica em `https://<usuario>.github.io/<repositorio>/`.

## Instalar no celular
- Android (Chrome): abra o endereço → menu ⋮ → **Instalar app**.
- iPhone (Safari): Compartilhar → **Adicionar à Tela de Início**.

## Atualizar
Troque o `index.html` e aumente a versão em `sw.js` (`custo-cozinha-v4` → `v5`).
